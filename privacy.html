ia-google - Privacy policy

ia-google is a personal tool. Its only user is its owner.

Data accessed

  • Google Tasks (scope https://www.googleapis.com/auth/tasks): task lists and tasks, to show, add, edit, move and complete them.

Storage and sharing

Data and the OAuth token are stored only on the owner's own computer. Nothing is sent to any server other than Google's APIs. No data is sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
